WINDOWS · C++17 · OPENCV 4.8 · DXGI

auto-24point

火拼 24 点自动答题器：DXGI 桌面复制截屏 → OpenCV 模板识别 4 张牌 → 查预计算解表 → 模拟鼠标点出算式，并可自动切题。

GitHub 仓库 使用文档

实测数据

0.317 µs单模板 NCC 匹配
0.17 ms4 张牌并行识别一轮
5.96 msDXGI 帧间隔 p50（≈167 fps）
22615预计算解表条目

工作流程

截屏

DXGI Desktop Duplication，只回读 4 张牌的包围盒

识别

二值化 → 紧框 → 居中 40×56 → 零均值归一化 → 点积

求解

22615 条解表，vector 直接寻址 O(1)

点击

QPC 高精度时序，移动等待 / 按下保持可调

切题

每轮结束后按 1→5 循环追加一次切题点击

快速开始

:: 1. 安装 OpenCV 4.8.1 到 C:\opencv
:: 2. 编译（需要 VS 2022 及以上）
compile_cpp.bat

:: 3. 把 opencv_world481.dll 复制到 exe 同目录，然后运行
auto_24point.exe

首次运行选择菜单 3 做可视化校准；菜单 1 进入监控，按 C 开始、V 停止、Esc 返回。

特性

零拷贝级截屏

只把目标区域 CopySubresourceRegion 到 staging 纹理，不搬整屏。

手写 NCC

与 TM_CCOEFF_NORMED 数学等价，实测分数偏差 4.17e-7。

常驻线程池

4 个 worker 各守一张牌，条件变量屏障，不识别时零 CPU。

可视化校准

4 套方案，拖拽牌位与运算符按钮，滚轮调整牌块尺寸。

精确时序

QPC 自旋补齐，1–60 ms 档位最大正误差 0.055 ms。

离线验证

7 个测试/基准工具，含留一法识别率与 NCC 等价性校验。
